The action control for Sentinel; `primary` is reserved for the single committing action in a view.

```jsx
<Button variant="primary" icon="shield-check">Run GOVERN</Button>
<Button variant="secondary" size="sm">Open audit trail</Button>
<Button variant="ghost" icon="ellipsis" />
```

Variants: primary (signal blue), secondary (default, white + hairline), ghost (toolbars), danger (destructive, never used for execution overrides). Sizes sm 26px / md 30px / lg 36px.
